# 献立カレンダー 仕様書（v1）

作成日: 2026-09-27
デザイン案: https://claude.ai/artifact/WGS4Z5aqU62sRefVJ8Kem4 （案1「台所ノート」を採用。月表示は「月 案A 格子」と「月 案B 縦リスト」の 2 モード）

## 1. 概要

自分ひとりが自分の Android 端末で使う献立管理アプリ。
プリセットまたは自作の料理をカレンダーの「日付 × 朝昼夜」の枠に当てはめ、今日の献立とレシピを確認し、必要な材料を買い物リストに集める。

## 2. 基盤

| 項目 | 決定 |
| --- | --- |
| 言語 / UI | Kotlin + Jetpack Compose |
| 永続化 | Room（端末内のみ） |
| モジュール構成 | 単一モジュール |
| minSdk / targetSdk | 26 / 35 |
| パッケージ名 | `com.github.mr04vv.kondatecalendar` |
| アプリ名 | 献立カレンダー |
| UI 言語 | 日本語のみ（多言語リソース分けなし） |
| 週の始まり | 月曜 |
| テーマ | 常に案1 のライト配色（端末のダークモードには追従しない） |
| バックエンド / ログイン / 外部 API | なし |

## 3. データモデル

### 3.1 料理（Dish）

| フィールド | 内容 |
| --- | --- |
| 名前 | 短めに付ける（例: 唐揚げ、鶏の照り焼き） |
| 絵文字 | 料理を表す 1 文字（🍛🍜🍣 など） |
| ジャンル | 1 つ。固定選択肢（3.3） |
| タイプ | 複数可。固定選択肢（3.3） |
| 材料 | 「材料名 + 分量（文字列）」のリスト。例: じゃがいも / 3 個 |
| 手順 | テキスト |
| 写真 | 自作料理のみ。端末のカメラまたはギャラリーから。プリセットは持たない |
| 所要時間の目安 | 分（任意） |
| 由来 | プリセット / 自作 |
| 作れる | 自分が作れる料理の印（真偽）。自作の料理は登録時に付いた状態になる |

- 分量は文字列のまま持つ。単位変換・人数スケーリングはしない。

インタビューで決めていない前提（異論があれば変更する）:

- 所要時間の目安を任意フィールドとして持つ。
- 由来（プリセット / 自作）を持ち、おすすめ抽出の対象をプリセットに限定するために使う。
- プリセットも自作も同じテーブルで扱い、プリセットも編集できる。

### 3.2 献立の枠（MealSlot）

- キーは「日付 × 時間帯（朝 / 昼 / 夜）」。
- 1 枠に入る料理は 1 品。
- 空き枠はレコードなしで表す。

### 3.3 タグ（固定）

| 軸 | 選択肢 | 表示 |
| --- | --- | --- |
| ジャンル（1 品 1 つ） | 和食、中華、洋食、韓国、エスニック、その他 | 軸ごとに色を事前定義し、カレンダーの色分けの主軸にする |
| タイプ（1 品複数可） | 丼、麺、肉、魚、卵、野菜、汁物、パン、ご飯もの | フィルタと小さなチップ表示に使う |

- ユーザーによるタグの追加・色変更はできない。

### 3.4 買い物リスト（ShoppingItem）

1 件は「1 つの出どころから入った 1 つの材料」を表す。画面ではこれを材料名ごとにまとめて表示する（4.6）。

| フィールド | 内容 |
| --- | --- |
| 材料名 | 文字列 |
| 分量 | 文字列 |
| チェック済み | 真偽 |
| 出どころの枠 | 日付と時間帯。枠から入れた材料のみ。レシピ詳細から入れた材料と手入力は持たない |
| 出どころの料理 | 料理と、入れた時点の料理名。手入力は持たない |

### 3.5 プリセット

- 200〜300 品を JSON として assets に同梱し、初回起動時に投入する。
- 手順・材料込み。内容は一般的なレシピ知識に基づく目安。
- 投入は冪等（2 回目以降の起動で重複しない）。

## 4. 画面

下部タブ 3 つ: カレンダー / 今日 / 買い物リスト。料理一覧の独立タブは持たない。

### 4.1 カレンダー

トグルで 2 モードを切り替える。

**格子モード（月）**
- 7 列の月格子。月曜始まりで 4〜6 行。前後の月へは左右スワイプまたは矢印で移動（格子部分だけが横にスライドする）。
- セルには夜の料理名を最大 3 行に折り返して表示（収まらない分は省略記号）。夜が空なら「未定」。
- 朝・昼はジャンル色の小さな丸で示す。
- 上部の「表示: 夜 / 昼 / 朝」で、名前を出す時間帯を切り替えられる。
- 今日の日付は反転表示。月外の日は薄く表示。
- 下部にジャンル色の凡例。

**リストモード**
- 1 日 1 行。左に日付と曜日、右に朝・昼・夜の 3 枠を横並び。
- 月をまたいで連続スクロール。開いたときは今日の位置まで自動スクロール。
- 週の切れ目に見出し行を置き、「この週の材料を買い物リストへ」ボタンを付ける。

**枠の操作（両モード共通）**
- 空き枠をタップ → 献立選択シート（4.2）。
- 埋まった枠をタップ → 「レシピを見る / 入れ替える / 空にする」の 3 択メニュー。
- ドラッグ & ドロップはしない。

### 4.2 献立選択シート（ボトムシート）

- タイトルに対象の日付と時間帯（例: 10/7（水）夜の献立）。
- 検索欄（料理名の部分一致）。
- ジャンルのフィルタチップ（すべて / 和食 / 中華 / …）とタイプのフィルタチップ。
- 絵文字 + 料理名のグリッド。タップで確定し、シートが閉じる。
- 「作れる」チップ: 「作れる」の印が付いた料理だけに絞り込む。ほかの条件と組み合わせられる。オン・オフはアプリを閉じるまで保持する。
- 料理を長押しすると「作れる」の印を付け外しできる。印の付いた料理はタイルにチェックを表示する。
- 「この条件でおすすめを出す」ボタン: 現在のフィルタ条件に合うプリセットからランダムに 1 品提示。「作れる」で絞り込んでいるときは、自作の料理も含めた「作れる」料理から選ぶ。
- 「＋ 新しい料理」: 料理の登録画面へ。

### 4.3 今日

- 今日の朝・昼・夜の 3 枠。左右の矢印で前後の日へ移動。
- 各枠: 絵文字、料理名、ジャンル・タイプのチップ、材料数と所要時間。タップでレシピ詳細へ。
- 夜の枠は大きめに表示し、材料の先頭数件を出す。「レシピを見る / 入れ替える」ボタン。
- 空き枠は「献立を決める」でそのまま選択シートを開く。
- 画面下に「今日の材料 N 品を買い物リストへ」ボタン。

### 4.4 レシピ詳細

- 絵文字（自作なら写真）、料理名、ジャンル・タイプのチップ、所要時間。
- 材料リスト、手順テキスト。
- 「作れる料理」チップで印を付け外しできる。
- 「買い物リストに追加」ボタン、編集ボタン。

### 4.5 料理の登録・編集

- 名前、絵文字、ジャンル（1 つ）、タイプ（複数）、材料（行の追加・削除）、手順、所要時間、写真（自作のみ）。

### 4.6 買い物リスト

- 1 本のリスト。追加元は「今日画面の一括追加」「レシピ詳細」「リストモードの週見出し」「手入力」。
- どの枠（日付 × 時間帯）の料理、またはどのレシピから入れた材料かを記録する。同じ出どころをもう一度追加しても二重に入れない（チェック済みで残っている分も含めて、入っていれば追加しない）。追加した品数をスナックバーで示し、すべて入っていたときは「すでに買い物リストに入っています」と出す。
- 枠を空にしたとき、または別の料理に入れ替えたときは、その枠から入れた未チェックの材料をリストから外す。入れ替え後の料理の材料は自動では入れない（もう一度「買い物リストへ」を押す）。
- チェック済みの材料は、枠を空にしても残す。
- レシピ詳細から入れた材料は枠に結び付かないので、枠を空にしても外れない。
- 同じ材料名（完全一致のみ）でチェック状態が同じものは 1 行にまとめ、分量を「3 個、200g」のように連結して表示。表記ゆれの吸収はしない。分量が空の材料は連結しない。チェック済みと未チェックは別の行になる。
- 各行の下に出どころを小さく表示する（例: 肉じゃが（10/7 夜）・カレー（レシピから））。手入力の材料は出どころを出さない。
- チェックで完了、スワイプで削除、手入力で行を追加。まとめた行へのチェック・スワイプは、その行にまとめたすべての材料に効く。
- チェックしても画面を開いている間は行の位置を動かさず、タブを開き直すとチェック済みが下にまとまる。
- 「チェック済みを消す」ボタン。チェック済みの材料は自動では消さない。

## 5. v1 でやらないこと

- 通知・リマインド
- ホーム画面ウィジェット
- データのエクスポート・インポート、バックアップ
- 複数カレンダー、ユーザー切り替え、家族との共有・同期
- 人数に応じた分量スケーリング、栄養・カロリー計算
- 料理の「作った履歴」、評価（お気に入りの代わりに「作れる」の印を実装済み）
- テーマ設定、ダークテーマ
- 楽天レシピなどの外部レシピ連携（クックパッドは公式 API がないため対象外）
- ドラッグ & ドロップでの配置
- 写真付きプリセット

## 6. テスト

ロジックのみ JVM ユニットテストで守る。Compose の UI テスト、Room のインストルメントテストは書かない。

- 買い物リストの同名まとめ（完全一致、分量の連結）
- カレンダーの日付計算（月格子の行数と範囲。月曜始まりで 4〜6 行になる。週の切れ目）
- おすすめ抽出（フィルタ条件を満たす候補からの選出、「作れる」絞り込み時は自作の料理も対象）
- プリセット投入の冪等性

ロジックは Room や Compose から切り離した純粋な Kotlin 関数として書く。
